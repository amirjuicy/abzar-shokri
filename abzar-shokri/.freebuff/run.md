# Abzar Shokri — Dev Server

## How to reproduce

No build step or dependencies required. The project is pure vanilla HTML/CSS/JS.

1. The `server.js` file at the project root is a self-contained Node.js static file server.
2. No `.env` files, no `node_modules`, no install step.

## How to run

```bash
cd C:\Users\INO\Desktop\abzar-shokri\abzar-shokri
node server.js
```

Default port: 3000. Override with `PORT=8080 node server.js`.
